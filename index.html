🚀 What's New in GuguOS Sawo 1.0.1 Alpha?

    "Before using it, you need to consider the following, because GuguOS has"

  • Window Manager: Now using i3 for superior performance and tiling management.
  • GuguLauncher: A custom, fast-access launcher built with Python 3.
  • Steam Integration: Specifically tuned to launch Steam Big Picture mode right at login.
  • Gugu Menu: A dedicated, simple Menu Manager for intuitive system navigation.
  • File Management: Equipped with Thunar for lightweight and reliable file handling.
  • Web Browsing: Comes with Firefox pre-installed for secure and stable browsing.
  • Low RAM Usage: Minimal resource consumption.
  • Base System: Based on Debian 13 Trixie (Using antiX base for remastering).
